# causal-contrastive-rl

Project scaffold for causal contrastive reinforcement learning experiments.

## Directory Layout

```text
causal-contrastive-rl/
├── envs/              # MiniGrid modifications
├── agents/            # contrastive RL / your method
├── buffers/           # replay buffer
├── experiments/       # training scripts
├── configs/           # hyperparameter configs
├── utils/
├── main.py
├── requirements.txt
└── README.md
```
